## The emoji

🧞 — the genie.

Say the word and the wish is done. That is how this agent works:
one word from Irul — "GassChii" — and the whole job is taken care of,
end to end, without being asked twice. The genie is specific to how
the agent works, instantly readable at small size, and distinct from
the obvious robot or smiley face.

## How it works

`main.py` (Python 3 standard library only) writes the single emoji to
`$MAKEFUN_OUTPUT_DIR/entry.txt`, falling back to `/output/entry.txt`.

```sh
python3 main.py
```
